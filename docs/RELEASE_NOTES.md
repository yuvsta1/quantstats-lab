# v0.1.0 — initial candidate release

QuantStats Lab introduces transparent, seeded probability and quant research utilities in a lightweight Python API and optional Streamlit visual interface.

Includes six probability distributions, mean inference, multiple-testing adjustment, geometric Brownian motion, return resampling, OU and AR(1), and descriptive portfolio risk metrics.

This is a research/educational **release candidate**. No live market data or broker execution is provided. See the mathematical caveats in `docs/MATH.md` and the verification checklist in `docs/QUALITY.md`.

**Created by Yuvi with the assistance of AI (OpenAI ChatGPT) for software development, testing, and documentation.**
