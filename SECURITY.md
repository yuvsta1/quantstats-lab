# Security policy

QuantStats Lab is intended for local analysis of non-sensitive data. It has no broker credentials, trading functionality, or user accounts.

## Reporting vulnerabilities

Please do **not** post passwords, personal data, tokens, or exploit details in public issues. Contact the repository maintainer privately using GitHub's private vulnerability reporting feature if enabled; otherwise request a private contact method through a minimal issue **without** confidential details.

Supported version: the latest `0.1.x` release candidate only. Security updates are best-effort and no service-level response time is promised.
