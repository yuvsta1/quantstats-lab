# Community code of conduct

Participants are expected to act professionally, be welcoming and inclusive, discuss ideas and mathematical disagreements respectfully, and avoid harassment, discrimination, personal attacks and disclosure of private information.

Report problematic behaviour privately to repository maintainers using an appropriate GitHub contact channel rather than disclosing personal information in public issues. Maintainers may moderate or remove contributions that violate these standards.
